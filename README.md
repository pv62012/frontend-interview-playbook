# Frontend Interview Playbook

A structured preparation repository for **Senior Frontend Engineer / SDE-2 interviews** at product-based companies.

## Objective

Master advanced frontend engineering concepts, architecture, performance, and interview problem-solving.

This repository prioritizes **interview readiness over project implementation**.

## Preparation Approach

### Phase 1 — Theory First

- React Internals and Performance
- Advanced TypeScript
- Design Systems and Design Tokens
- Storybook
- Webpack and Module Federation
- React Testing
- Frontend System Design
- Machine Coding Concepts
- Behavioral and Resume-Based Interviews
- Mock Interviews

### Phase 2 — Practical Implementation

After theory preparation:

- Machine Coding Challenges
- Production-Grade React Design System
- Storybook and Component Libraries
- Testing and Performance Optimization
- Frontend Architecture Projects

## Learning Method

Every topic follows a senior-engineer interview approach:

1. Internal Working
2. Why It Exists
3. Production Use Cases
4. Architecture and Trade-offs
5. Performance Considerations
6. Interview Questions and Follow-ups
7. Common Mistakes
8. Revision Notes

**One interview question at a time.**
