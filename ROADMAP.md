# Senior Frontend / SDE-2 Interview Roadmap

## Primary Goal
Become interview-ready for Senior Frontend / SDE-2 roles at product companies as quickly as possible.

Interviews may be scheduled at any time.

## Preparation Strategy

**Phase 1: Theory First (Highest Priority)**

1. React Internals and Performance
2. Advanced TypeScript
3. Design Systems and Design Tokens
4. Storybook Concepts and Architecture
5. Webpack and Module Federation
6. React Testing Concepts
7. Frontend System Design
8. Machine Coding Concepts and Problem-Solving Strategies
9. Behavioral and Resume-Based Interviews
10. Mock Interviews and Revision

For each topic, cover:
- Internal working and architecture
- Why it exists
- Real-world production use cases
- Trade-offs and performance
- Common mistakes
- Senior-level interview questions and follow-ups
- Resume-based examples where applicable

## Phase 2: Practical Implementation

Start only after Phase 1 theory preparation is completed.

- React machine coding
- Production-grade design system
- Storybook implementation
- Component testing
- Webpack configuration
- Frontend system design implementations

## Learning Rules

- One question at a time.
- Challenge weak answers with follow-up questions.
- Avoid beginner-level React explanations.
- Prioritize interview readiness over project development.
- Maintain progress in INTERVIEW_PROGRESS.md.
- Commit updated progress to GitHub after each session.
- Use repository documentation to resume in future ChatGPT conversations.
